# HPAnalytic — Referans Repolar

Sitenin görsel ve analitik dilini besleyecek kaynak kodlar. Her biri kendi alanında örnek alınacak.

## Analitik Metodoloji
- github.com/harshkrishna17 — Veri görselleştirme eleştirisi, spor analitiği UI/UX
- github.com/eddwebster/quantifying-soccer-pressure — PPDA, pres metrikleri
- github.com/eddwebster/football-data-analytics — Genel futbol analitiği
- github.com/eddwebster/soccerdata — **ÖNCELİK:** Veri çekme, zenginleştirme, xG/PSxG hesaplama
- github.com/eddwebster/Football-Analytics-With-Python — Python analiz örnekleri

## Görselleştirme ve Animasyon
- github.com/eddwebster/soc-viz-of-the-week — Haftalık görsel örnekler, ilham
- github.com/eddwebster/Pass-Flow — **ÖNCELİK:** Pas akışları, animasyon, GIF üretimi
- github.com/willkurt/Workflow-visualization — Akış görselleştirme
- github.com/parmacalcio1913/line-breaking-passes — Hat kırma pasları görselleştirmesi

## Modelleme ve İstatistik
- github.com/willkurt/gorilla — Fonksiyonel veri manipülasyonu
- github.com/willkurt/evenflow — Event data işleme
- github.com/willkurt/MarkovLab — Markov zinciri modelleri
- github.com/twiecki/scikit-learn — ML temel kütüphane (referans)

## Uygulama Notları
1. `soccerdata` çözüldüğünde HPAnalytic veri hattı otomatik zenginleşir.
2. `Pass-Flow` çözüldüğünde saha üstü pas animasyonu mümkün.
3. `line-breaking-passes` çözüldüğünde "hat kırma" analizi görselleşir.
4. `MarkovLab` + `evenflow` birlikte kullanılırsa oyun-içi durum geçişleri modellenebilir.
