# Security reporting

This is a private product repository. Do not open a public issue containing a vulnerability, credentials, personal data or unreleased source.

Report security findings through the authorized HPANALYTIC operations channel. Include affected revision, a minimal non-secret reproduction, severity, and suggested containment. Do not send tokens, keys or raw private user data.

Treat the private editorial studio, phone/Termux adapters and production deployment credentials as separate trust boundaries. Changes to authentication, deployment or secret handling require explicit authorization and independent review.

Security checks in this repository are supporting evidence, not a substitute for a full threat model or rights audit.
