# HPAnalytic OpenCode SuperSkills v0.1

Project-local skills in `.opencode/skills/<id>/SKILL.md` are discovered by OpenCode automatically when launched from this Git worktree.

- `hp-supervisor` — orchestration and safety gates
- `hp-football-analysis` — event-only evidence and prematch/postmatch mechanisms
- `hp-editorial-storytelling` — article thesis and narrative architecture
- `hp-viz-engineering` — 105×68 pitch, charts, club colors, dropdowns, animation
- `hp-visual-qa` — visual, editorial, browser and deployment acceptance

Invoke `hp-supervisor` for multi-disciplinary work; it specifies when to load the remaining four. The on-demand `skill` tool makes these discoverable; merely creating files does not mean a running agent has loaded them.

These skills are provisional v0.1 and require improvement via real match outputs and independent QA. They grant **no** permission to publish, delete, spend, merge or deploy.
