Accessibility: the libraries do not automatically make an output accessible. Actual HP components use labelled native buttons, pressed states, roving arrow-key focus for spatial bins, linked textual evidence, source HTML, and table alternatives. Reduced motion disables automatic progression; no forced scroll or autoplay. Existing mathematical functions kdeField, kdeRender and pitch remain byte-identical to the deployed archive; layout, annotation and selection adapters change.

Security: no remote code executed or fetched at page runtime. No CDN dependency, third-party iframe, analytics integration or new collection of personal data. No claim that repository reputation replaces dependency/security review. Since no third-party code was copied, there is no new licence/NOTICE redistribution burden. Existing bundled font licences remain intact.
