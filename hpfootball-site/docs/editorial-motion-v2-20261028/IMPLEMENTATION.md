# Motion and editorial correction

The user rejected the static node-only goal viewer and oversized unstyled share controls. The rebuilt viewer animates a schematic point between observed event coordinates, reveals the chronological links, supports pause/scrub/speed/previous/next and goal tabs, and pauses when hidden. It does not invent pass recipients, measured ball trajectories or player runs.

The new xGrid scene uses published 12×8 numerical xT parameters and exact previously published event displacement vectors (398 GS,229 FB). The surface is a general model; no match xT total is claimed. Particles visualize the smoothed displacement field, not physical player/ball tracking. The existing source arrays and six chart calculation engines remain unchanged.

Share controls use an explicit 12px interface stack and 44px hit areas. Visual chart-control faces are 28px within 44px targets. Share cancellation clears the status instead of displaying a pointless message.

FC Barcelona and MIT Sloan official portraits were downloaded and identity-checked for private art-direction review. The 1200×750 FC Barcelona conference portrait is visible only when DEV and HPA_PHOTO_REVIEW=1, through the local dev filesystem server. Image assets and portrait screenshots are not committed or published. Reproduction permission is not established; this is not represented as a licensed public photo.
