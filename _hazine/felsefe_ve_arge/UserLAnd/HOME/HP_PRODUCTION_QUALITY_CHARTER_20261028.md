# Independent Production Quality Charter — 2026-10-28

Scope: voluntary operating brief for new work; does NOT override existing project contracts or change running processes.

## Roles
1. Analyst: identifies admissible primary data, schema, uncertainty, and measurable football claim.
2. Researcher: gathers sources, maintains verifiable references, flags contested interpretations.
3. Art director: independently chooses composition and visual grammar appropriate to the specific story. Do not inherit HPFA/HPAnalytic palettes, typography, layout or geometry unless that project specifically requests them.
4. Engineer: implements reproducible outputs with lint/tests, mobile and desktop exports.
5. Reviewer: separate pass/fail verification against source truth, editorial clarity, visual hierarchy, technical correctness, and mobile usability.

## Output contract
- Produce a short decision brief, output artifacts, and source manifest.
- Graphics: visual thesis, input provenance, axis/scale validation, legibility at publication sizes, layer/source manifest when applicable.
- Article: verified claim ledger and original coherent narrative; no invented quotes/data.
- Video: storyboard, script, subtitles, source/rights notes, platform aspect ratios.
- Do not mark complete because an artifact merely exists.
- Iteration is automatic only within task scope; stop and report irreducible blockers.
- Never publish, post to social networks, pay for cloud services, destroy data, or change canonical repositories without explicit approval.

## Device efficiency
- Prefer existing binaries and venvs; isolate dependencies.
- No persistent background daemon unless the user requested it.
- Serialize heavyweight renders and Chromium tasks when RAM pressure is high.
- Offload video render only after cost/privacy approval.
- Capture before/after resource telemetry for optimization claims.

## Acceptance gates
A. Evidence integrity: PASS/FAIL
B. Narrative usefulness: PASS/FAIL
C. Art direction and legibility: PASS/FAIL
D. Cross-device QA: PASS/FAIL
E. Reproducibility: PASS/FAIL
F. Safe release: REVIEW REQUIRED

This document is a draft for independent new work, not a global policy for historic projects.
