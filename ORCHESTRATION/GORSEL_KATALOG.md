# HPANALYTIC — VERİDEN GÖRSELE KATALOĞU

## 1. players.csv (Olay Verisi - Koordinatlı)
- [x] Konumlanma Haritası (Formasyon -> Defansif -> Ofansif, İz Bırakmalı)
- [ ] Pas Ağı (Akan çizgiler, en sık pas koridorları)
- [ ] Şut Haritası (xG büyüklüğüne göre)
- [ ] Top Kaybı/Kazanma Haritası (Bölgesel ısı haritası)

## 2. players.xlsx (Oyuncu Toplam İstatistikleri)
- [ ] xG / xA Karşılaştırma Çubukları
- [ ] Oyuncu Radar Grafiği (6-8 metrik)
- [ ] Pas İsabet Matrisi

## 3. teams.csv (Takım Verisi)
- [ ] Momentum Grafiği (Baskı yoğunluğu zaman çizelgesi)
- [ ] Alan Hakimiyeti (Territory Control)
- [ ] Topa Sahip Olma Akış Şeridi

## 4. goalkeepers.xlsx (Kaleci Verisi - YENİ!)
- [ ] **Kaleci Kurtarış Haritası (Shot Stopping):** Kale çizgisi üzerinde, kurtardığı ve yediği gollerin yerlerini gösteren interaktif bir kale kafesi. (OxG - Önlenen Gol verisiyle desteklenmiş).
- [ ] **Süpürücü Kaleci (Sweeper Keeper) Haritası:** Kalecinin ceza sahası dışında topu kazandığı (Sweeping Actions) noktalar. Onun "modern bir libero" gibi oynayıp oynamadığını gösterir.
- [ ] **Dağıtım Ağı (Distribution):** Kale vuruşlarının (Goal kicks) kısa/orta/uzun olarak nereye gittiğini gösteren, GSAP ile topun kaleci ayağından çıktığı andan itibaren akan animasyon.
- [ ] **Supersave (Kritik Kurtarış) Zaman Çizelgesi:** Maçın en kritik anlarında yaptığı kurtarışların zaman çizelgesi.
